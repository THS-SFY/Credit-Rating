# CreditScore Pro 🛡️

**CreditScore Pro** — это современная полнофункциональная система автоматизированной оценки кредитоспособности физических лиц. Проект объединяет мощный Backend на Java Spring Boot и интуитивно понятный Frontend на Node.js.

## 🚀 Основные возможности

*   **Интеллектуальный скоринг:** Автоматическая проверка ИНН через официальные API (ФНС) и эмуляция запросов к ФССП, КАД Арбитр и Контур.Фокус.
*   **Умная CRM-система:** Ведение базы клиентов с автоматическим сопоставлением данных по ИНН.
*   **Безопасность Enterprise-уровня:** Авторизация на базе JWT (JSON Web Tokens), шифрование паролей BCrypt.
*   **Защита данных:** Встроенные механизмы защиты от SQL-инъекций, XSS-атак и DDoS (Rate Limiting).
*   **Современный UI/UX:** Адаптивный дизайн на Bootstrap 5.3 с плавными анимациями (Animate.css).

---

## 🛠 Технологический стек

### Backend (Серверная часть)
- **Язык:** Java 21 (OpenJDK)
- **Фреймворк:** Spring Boot 3.5 (Web, Data JPA, Security)
- **База данных:** H2 (In-memory для удобства деплоя)
- **Безопасность:** Spring Security + JWT
- **Сборка:** Maven

### Frontend (Клиентская часть)
- **Платформа:** Node.js + Express.js
- **Шаблонизатор:** EJS (Embedded JavaScript)
- **Стили:** Bootstrap 5.3 + Custom CSS
- **Безопасность:** Helmet, express-rate-limit, xss

## 📦 Быстрый запуск

Подробная инструкция по запуску и установке на сервера (Ubuntu/Arch) находится в файле [GUIDE.md](./GUIDE.md).

### Коротко:
1.  **Запуск Backend:**
    ```bash
    cd backend
    ./mvnw spring-boot:run
    ```
2.  **Запуск Frontend:**
    ```bash
    cd frontend
    npm install
    npm start
    ```
3.  **Открыть в браузере:** `http://localhost:3000`
